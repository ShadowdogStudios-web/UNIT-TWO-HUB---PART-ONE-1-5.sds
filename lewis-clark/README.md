# Corps of Discovery: Westward — Four-Act Jump Edition

## New arcade refinements
- Larger desktop playfield
- River hazards vary from roughly 70% to 145% in size
- Fleet receives a modest 95%–107% size variation per new expedition
- New river Jump / Surge mechanic
- Space = Jump
- Controller A = Jump
- P = Pause
- Controller Start = Pause
- Jump has a short cooldown
- Rocks, snags, and sandbars can be cleared with good timing
- Larger hazards need a higher/better-timed jump
- Rapids cannot be jumped
- Jump-clearing a hazard earns a small score bonus
- Collision radius and damage now scale with hazard size
- Boat/fleet rises while wake and shadow remain at water level

## Four-act campaign
1. Up the Missouri
2. Upper Missouri & Great Falls
3. Bitterroot Crossing
4. Columbia to the Pacific
